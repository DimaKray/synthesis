# Capitalism: Синтез

Мод для збірки **Capitalism** (Minecraft 1.21.1, NeoForge): машини й вівтарі, що об'єднують моди збірки — мана Ботанії, джерело Ars Nouveau, енергія FE і обертання Create в одній системі.

## Статус
Етап 1 — скелет мода: вкладка «Синтез», Сплави єдності I–III, Скіпетр синтезу (поки без функцій).

## Збірка
Кожен push у `main` збирається GitHub Actions; готовий jar з'являється в **Releases**.

Локально (потрібен JDK 21): `./gradlew build` → `build/libs/`.
