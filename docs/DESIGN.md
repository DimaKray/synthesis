# Capitalism: Синтез — дизайн-документ мода

Власний мод Дмитра для збірки Capitalism. Машини й вівтарі, які **споживають «валюти» різних модів одночасно** — ману Ботанії, джерело Ars Nouveau, енергію FE, обертання Create, рідини — і роблять компоненти, яких не отримати ніде більше. Мета: зробити з набору модів одну систему. Друга мета — **машини, що спрощують грінд ресурсів**, бо збірка дуже ресурсоємна. Орієнтир за духом — сервер **LoliLand TechnoMagic RPG** і його власні моди (розділ 2.7).

- **Назва:** Capitalism: Синтез
- **mod id:** `synthesis`
- **Пакет:** `ua.krainov.synthesis`
- **Платформа:** Minecraft 1.21.1, NeoForge 21.1.267, Java 21 (потім перенос на 26.x)
- **Ліцензія:** MIT
- **Розробка:** через Claude Code на ПК Дмитра (контекст у `CLAUDE.md` і `docs/DESIGN.md` у репозиторії `DimaKray/synthesis`). У збірці зараз `synthesis-0.6.0.jar`.

## Прийняті рішення
- Текстури генеруємо в стилі збірки (16×16 піксель-арт, ванільна палітра)
- Ритуали запускаються **Скіпетром синтезу** (без редстоуну)
- **Конвертера валют не робимо** — щоб не ламати баланс модів
- **Ману з гравця (Iron's Spells) не беремо**
- **Вівтар Капіталізму — мультиблок 9×9 з 21 п'єдесталом** (по одному на кожен ключ Infinity Catalyst)
- З ідей LoliLand беремо: **Капітал-бокси, Капітал-панелі, Промисловий процесор**. Не беремо (поки): Біржу й монети, Пекельну піч, Квантовий реплікатор, щоденні нагороди, приватні виміри
- ME-кабелі «на 256 каналів» — не в моді, а конфігом AE2 (`channels = "X4"`: звичайний кабель 32, щільний 128)

## 2. Блоки й машини

### 2.1 П'єдестал синтезу (`synthesis:pedestal`)
- Тримає один предмет, показує його над собою (обертається, левітує).
- ПКМ кладе або забирає предмет. Сумісний з хопером і трубами Create.

### 2.2 Стабілізатор душ (`synthesis:soul_stabilizer`) — машина для грінду
**Ідея:** кладеш у машину **душу моба з Draconic Evolution** (`draconicevolution:mob_soul`, падає з мобів, убитих зброєю з зачаруванням Reaper/«Жнець»), ставиш поруч скриню — і туди постійно падає лут, який мав би випасти з цього моба. **Моби не спавняться**, тож ні лагів, ні ферм-кілерів.

**Механіка:**
- 1 слот для душі. Без душі машина стоїть.
- Кожен цикл машина створює сутність моба **в пам'яті, не спавнячи її у світ**, і кидає **його таблицю луту** (`entityType.getDefaultLootTable()`) з `LootParams`: `THIS_ENTITY`, `ORIGIN`, `DAMAGE_SOURCE` = удар гравця (FakePlayer), `LAST_DAMAGE_PLAYER` = FakePlayer. Плюс модові дропи через `LivingDropsEvent`, якщо можливо.
- Результат кладеться в **будь-який сусідній інвентар** через `Capabilities.ItemHandler.BLOCK`. Інвентар повний — пауза, нічого не губиться.
- Живлення: **FE**. Вартість циклу залежить від здоров'я моба (`maxHealth × коефіцієнт`).
- Досвід: опційно в рідину досвіду в сусідній бак.

**Рівні (прив'язка до прогресії Draconic):**
| Рівень | Крафт (ядро) | Цикл | Лутинг | Мобів за цикл |
|---|---|---|---|---|
| Базовий | Драконієве ядро | 20 с | — | 1 |
| Віверна | Ядро Віверни | 10 с | I | 1 |
| Пробуджений | Пробуджене ядро | 5 с | II | 2 |
| Хаотичний | Хаотичне ядро | 2 с | III | 4 |

**Боси — дозволені, повний лут (рішення Дмитра 20.11).** Душі босів не падають з босів, а **крафтяться** на Extreme Crafting Table (`kubejs/server_scripts/capitalism_boss_souls.js`, 44 боси: ванільні, Сутінковий ліс, Cataclysm, DivineRPG, Охоронець Гаї, Хаос-охоронець, Вайлден-Хімера, боси Extra Botany). Результат — `draconicevolution:mob_soul` з компонентом `draconicevolution:soul_id` = id боса.
- Душа боса працює **лише в Стабілізаторі рівня Пробуджений або Хаотичний** (базовий/Віверна показують «Замало сили для душі боса»).
- Боса визначаємо за тегом `c:bosses` (+ список у конфігу `extraBosses` для тих, хто без тегу: `minecraft:wither`, `minecraft:ender_dragon`, `minecraft:warden`, `minecraft:elder_guardian`, `draconicevolution:draconic_guardian`).
- Для боса: цикл ×5 довший, FE ×10 (або за `maxHealth`), лутинг рівня як звичайно. Лут — повний, включно з ключами фіналу.
- Особливі випадки: Дракон Енду — таблиця луту порожня (лут/досвід видається в коді ванілі), тому даємо замість неї конфігурований дроп (`dragonLoot`, за замовчуванням — `minecraft:dragon_breath` ×4 і досвід); Візер — зірка Незеру; Хаос-охоронець — `draconicevolution:chaos_shard` (у DE дроп у коді) — перевірити в розробці й за потреби задати в конфігу `bossLootOverrides` (entity → список предметів).
- Чорний список у `synthesis-common.toml` лишається для мобів, яких не можна симулювати (за замовчуванням порожній).

**Візуал:** мініатюра моба в блоці (як у Draconic Stabilized Spawner), частинки душ, гул.

### 2.3 Вівтар Злиття (`synthesis:fusion_altar`)
**Мультиблок:** вівтар у центрі та 4–8 п'єдесталів у радіусі 3 блоків.
1. У вівтар кладеш центральний предмет, на п'єдестали інгредієнти.
2. ПКМ **Скіпетром синтезу** запускає ритуал (Shift+ПКМ — показати, чого бракує).
3. Вівтар тягне **ману** з мана-розповсюджувачів (`ManaReceiver`), **джерело** з банок Ars поряд (`SourceUtil`), **FE** через кабель.
4. Частинки летять від п'єдесталів до центру, звук наростає.
5. Готово: предмети з п'єдесталів зникають, у центрі результат.
6. Ресурси закінчилися — прогрес зупиняється, але не губиться.

### 2.4 Техно-магічний синтезатор (`synthesis:synthesizer`)
- Інтерфейс: 3 вхідні слоти, 1 вихід, бак рідини, буфер FE.
- Блок кінетичний (вал Create збоку): мінімальні RPM і навантаження (stress).
- Швидкість крафту залежить від RPM.

### 2.5 Вівтар Капіталізму (`synthesis:capital_altar`) — фінал
**Мультиблок 9×9:** центр + **21 п'єдестал** (по одному на кожен ключ фіналу), порти Мана / Джерело / Енергія / Обертання / Рідина.
**Крафтить Infinity Catalyst** (рецепт Avaritia прибираємо через KubeJS). Промені від 21 п'єдестала сходяться в центр. Аналог «Квантового генератора» LoliLand — предмета, що поєднує всі моди.

**21 ключ (зараз у `kubejs/server_scripts/capitalism_endgame.js`):**
draconicevolution:chaotic_core, botania:gaia_ingot, tc4modern:primordial_pearl, ttinkerer:ichorium, mekanism:pellet_antimatter, witchery:infernal_animus, cataclysm:cursium_ingot, industrialupgrade:neutroniumingot, twilightforest:fiery_ingot, ars_nouveau:wilden_tribute, irons_spellbooks:legendary_ink, create:precision_mechanism, ae2:quantum_entangled_singularity, powah:crystal_nitro, oritech:unholy_intelligence, neovitae:blood_orb_transcendent, occultism:book_of_binding_bound_marid, forbidden_arcanus:eternal_stella, extrabotany:orichalcos_ingot, mysticalagradditions:insanium_ingot, divinerpg:mortum_heart.

### 2.7 Машини в дусі LoliLand (TechnoMagic RPG)
Орієнтир — сервер LoliLand TechnoMagic RPG (1.7.10): власні моди LoliEnergistics, LoliTechnologies, LoliMagically, LoliDragonMight, LoliBotanicalMachinery.

**Прискорювач (`synthesis:accelerator`)** — аналог «Просунутих прискорювачів» LoliEnergistics.
- Ставиться поруч з машиною (будь-якою, що має BlockEntity з тіком) і прискорює її тіки.
- Живлення FE; рівні ×2 / ×4 / ×8 / ×16 (крафт через ядра Draconic або Сплави єдності).
- Чорний список у конфігу (спавнери, вівтарі ритуалів, реактор Draconic, нейтронний збирач Avaritia, лазерна база IF, Стабілізатор душ і Капіталістичні панелі — щоб не ламати баланс).

**Мультитеплиця (`synthesis:multi_greenhouse`)** — аналог Мультитеплиці LoliBotanicalMachinery.
- До 32 генеруючих квітів Ботанії як предметів у слотах; режим «Стак» (стак однакових квітів = N квітів).
- Мана/с для кожного типу квітки — фіксовані значення в конфігу; паливо квітки — у слот палива.
- Віддає ману в розповсюджувачі/басейни через API Ботанії.

**Драконієвий розповсюджувач (`synthesis:draconic_spreader`)** — велика пропускна здатність (орієнтир: до 25 млн мани).
**Великий басейн мани (`synthesis:great_mana_pool`)** — величезна місткість (орієнтир: до 2 млрд мани), рівні.

**Квантовий збирач 9×9 (`synthesis:quantum_assembler`)** — аналог автокрафту 9×9 LoliTechnologies.
- Приймає шаблони AE2 для рецептів Extreme Crafting Table (`avaritia:shaped_table` / `avaritia:shapeless_table`) і крафтить їх автоматично з мережі AE2.
- Найскладніша інтеграція (API AE2 crafting), робиться пізно.

**Що закривають готові моди / конфіги:** ExtendedAE (постачальники/інтерфейси на 36 слотів, матриця збирача), AdvancedAE (Квантовий комп'ютер), MEGA Cells (комірки до 256M), DivineRPG (RPG-виміри), Industrial Foregoing (лазерний бур руди), конфіг AE2 `channels = "X4"` (кабелі 32/128 каналів).

**Не повторюємо:** прискорювач рунічної матриці й інфернальну піч Таумкрафту — у неофіційного порту невідомий API.

### 2.8 Перетворювач удачі (`synthesis:fortune_converter`)
**Ідея:** блок, що «дробить» руду з удачею. Пара до лазерного бура Industrial Foregoing: бур дає руду → Перетворювач множить її удачею → (з модулем плавки) одразу злитки.

**Входи:** слот інструмента (кирка/бур з Fortune або Silk Touch; рівень з інструмента) **або** Модуль удачі I–V (V — вище ванільного максимуму, лише з пізніми крафтами; береться більший рівень); слот модуля плавки; вхід руди з сусіднього інвентаря / труб.

**Механіка:**
1. Береться блок руди (`BlockItem`, теги `c:ores`).
2. Кидається **таблиця луту блоку** з `LootParams`: `ORIGIN`, `BLOCK_STATE`, `TOOL` = віртуальна копія інструмента з потрібним рівнем Fortune/Silk Touch, `THIS_ENTITY` = FakePlayer. Удача працює рівно як у ванілі й модах.
3. **Модуль плавки:** результати проганяються через `minecraft:smelting`.
4. Результат — у сусідній інвентар; повний — пауза. Інструмент не зношується.

**Запасний режим для «сирої» руди** (`raw_*`/самоцвіти): множник за таблицею в конфігу, що імітує формулу Fortune. Вмикається в `synthesis-common.toml`.
**Живлення:** FE; вартість росте з рівнем удачі та модулем плавки. **Баланс:** чорний список блоків; модулі IV–V — після Сплаву єдності II/III.

### 2.9 Капітал-бокси (`synthesis:capital_box_*`) — аналог лоли-боксів
**Ідея:** як на LoliLand — гравець просто грає, і час від часу отримує бокс з безкоштовним лутом.

**Видача:**
- Лічильник **активного часу в грі** для кожного гравця (зберігається в даних гравця; AFK не рахується — якщо гравець не рухався/не діяв N хвилин, лічильник стоїть).
- Кожні **60 хв** активної гри — **кидок шансу** (за замовчуванням 35%) отримати бокс.
- Рідкість боксу: звичайний 70% / рідкісний 22% / епічний 7% / легендарний 1%.
- **Бонус вихідних:** у суботу й неділю (за часом сервера) шанс кидка ×1.5, максимум 50%.
- Бокс кладеться в інвентар (повний — падає під ноги), повідомлення в чат: «Дмитро отримав ЛЕГЕНДАРНИЙ Капітал-бокс!» — для легендарного всім гравцям сервера.
- Усі числа — у `synthesis-server.toml` (інтервал, шанс, ваги рідкостей, множник вихідних, AFK-таймаут, чи оголошувати всім).

**Відкриття:**
- ПКМ боксом — коротка анімація (бокс крутиться, частинки кольору рідкості, звук), потім лут у інвентар.
- **Лут — у таблицях луту датапаку**: `data/synthesis/loot_table/boxes/common.json`, `rare.json`, `epic.json`, `legendary.json`. Правиться без перезбірки (через KubeJS чи датапак збірки).
- Орієнтир луту: звичайний — ресурси раннього етапу (залізо, латунь, манасталь, редстоун, їжа); рідкісний — злитки середини (осмій, драконій, тауміум, самоцвіти джерела); епічний — компоненти (схеми Mekanism, ядра Draconic, руни Ботанії, книги зачарувань); легендарний — рідкісне (зірка Незеру, сингулярність, злиток нескінченності з малим шансом, яйце дракона). **Ключів фіналу в боксах немає.**

**Предмети:** 4 бокси з рідкістю в назві (кольори: білий/синій/фіолетовий/золотий), текстури в стилі збірки.
**Команди адміна:** `/synthesis box give <гравець> <рідкість>`, `/synthesis box timer <гравець>` (скільки до наступного кидка).

### 2.11 Промисловий процесор (`synthesis:industrial_processor`) — переробка стаками, як на LoliLand
**Ідея:** машина, що переробляє ресурси **цілими стаками** за одну операцію.

**Режими (перемикач в інтерфейсі):**
- **Плавка** — рецепти `minecraft:smelting` (будь-які модові рецепти печі теж).
- **Дроблення** — рецепти дроблення Create (`create:crushing`) або збагачувача Mekanism (`mekanism:enriching`) — що знайдеться для предмета; якщо мод відсутній — режим ховається.
- (Опційно пізніше) **Пресування** — `create:pressing`.

**Механіка:**
- Вхідний слот (стак), вихідні слоти, слот **Стекового модуля I–III**: без модуля — 8 предметів за операцію, I — 16, II — 32, III — 64.
- Час операції фіксований (напр. 5 с), FE за операцію = кількість предметів × базова вартість.
- Вхід/вихід з усіх боків (хопери, труби, AE2), налаштування сторін — просте (вхід зверху/збоку, вихід знизу).
- Сумісний з Прискорювачем.
**Баланс:** Стековий модуль III — після Сплаву єдності II.

## 4. Місце в прогресії Capitalism
- **Капітал-бокси**: з першої хвилини гри — постійна приємна дрібниця.
- **Стабілізатор душ**: після першого драконієвого ядра. Боси — пізніше: дорогі крафтові душі + Пробуджений/Хаотичний рівень.
- **Перетворювач удачі**: середній етап (разом з лазерним буром IF); Модулі удачі IV–V — пізній.
- **Прискорювач**: середній етап, рівні ростуть з ядрами Draconic.
- **Капітал-панелі**: гібридна — середина, нескінченна — фінал.
- **Промисловий процесор**: середній етап; Стековий модуль III — пізній.
- **Мультитеплиця, Драконієвий розповсюджувач, Великий басейн**: середній–пізній етап Ботанії.
- **Сплави єдності I–III**: мости до ядер Draconic, SPS, нейтронного збирача.
- **Квантовий збирач 9×9**: пізній етап.
- **Вівтар Капіталізму**: єдиний спосіб зробити Infinity Catalyst.
- Квести: новий розділ «10. Синтез».

## 5. Технічна архітектура

**Середовище:** NeoForge 21.1.267, ModDevGradle 2.0.141, Java 21, Gradle 8.14.3.

**Залежності (compileOnly):** Draconic Evolution + BrandonsCore (для `MobSoul`), Botania Revived (API `velrondevs.botania.api`, локальний jar у `libs/`), Ars Nouveau, Create, Mekanism (рецепти збагачення), AE2 (для Квантового збирача), Re:Avaritia, JEI API. Jar-файли брати з mods профілю Capitalism. Бокси, панелі й Перетворювач удачі залежностей не мають.

**Пакети:**
```
ua.krainov.synthesis
 ├─ SynthesisMod            (точка входу)
 ├─ registry/               (блоки, предмети, BlockEntity, рецепти, меню, вкладка, attachments гравця)
 ├─ block/ + blockentity/
 ├─ recipe/
 ├─ multiblock/
 ├─ box/                    (таймер активної гри, видача, відкриття, команди)
 ├─ compat/                 (draconic/, botania/, ars/, create/, mekanism/, ae2/, avaritia/, jei/ — тільки якщо мод завантажений)
 ├─ core/                   (ЛОГІКА БЕЗ MINECRAFT — для легкого переносу)
 └─ client/                 (рендерери, частинки, інтерфейси, анімація відкриття боксу)
```

**Робочий процес:** Claude Code на ПК Дмитра пише код і пушить у `DimaKray/synthesis`; GitHub Actions збирає jar і публікує в Releases; jar копіюється в mods профілю Capitalism; Дмитро тестує в грі.
